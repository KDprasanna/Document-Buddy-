✈️ Passport Application

Understand the commonly required documents and steps involved in applying for a passport.

📄 Required Documents

  • Proof of identity
  • Proof of address
  • Date-of-birth proof, when required
  • Recent photograph, if required
  • Existing passport, if applying for reissue
  • Additional documents depending on the application type

👤 Who Can Apply?

Eligible Indian citizens can apply for a passport. The documents and process may differ depending on whether it is a fresh application, renewal or reissue.

📝 Step-by-Step Process

  1. Identify the appropriate passport application type.
  2. Check the current document requirements.
  3. Complete the passport application form.
  4. Pay the applicable application fee.
  5. Attend the required appointment and verification.
  6. Track the application using the available reference details.

⚠️ Common Mistakes

  • Entering incorrect personal information
  • Providing documents with mismatched details
  • Missing the appointment
  • Uploading unclear documents when online submission is required
  • Not checking the application details before submission
